# 🏫 GLGMNHS Mock-up

A modern and responsive school website mock-up for **General Licerio Geronimo Memorial National High School (GLGMNHS)**.

This project is created as a **frontend web design and development mock-up**, focusing on modern UI/UX, responsive layouts, school branding, and accessible navigation.

## 📌 Project Overview

The GLGMNHS Mock-up is a conceptual school website designed to provide a modern digital presence for the school.

The design uses the school's **red visual identity** while incorporating modern web design techniques such as:

* Responsive layout
* Modern navigation
* Hero section with background imagery
* Red-themed visual design
* Clear content hierarchy
* Smooth navigation between sections
* Accessible HTML structure
* Clean and maintainable CSS

The project is currently being developed as a **mock-up/prototype** and may be expanded with additional pages and functionality in the future.

## 🎨 Design Direction

The website follows a **modern red-themed visual identity** inspired by the school.

Instead of relying on a flat red background, the design combines:

* Deep and bright red tones
* Background imagery
* Gradient overlays
* White typography
* Subtle shadows
* Modern spacing
* Interactive hover effects

The goal is to create a website that feels **professional, modern, welcoming, and appropriate for an educational institution**.

## 🏗️ Current Sections

The landing page currently focuses on the following sections:

### Hero Section

Introduces GLGMNHS with a large background image, school branding, introductory content, and navigation actions.

### About School

A dedicated section intended to present information about the school's history, mission, vision, and values.

### School Events

A section intended to showcase school activities, announcements, programs, and upcoming events.

### Organization

A section intended to introduce student organizations, clubs, and other school communities.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/glnplmrqz/glgmnhs-mock-up.git
```

### 2. Navigate to the project

```bash
cd glgmnhs-mock-up
```

### 3. Open the project

Since this is a frontend HTML/CSS project, no package installation is currently required.

You can open `index.html` directly in your browser or use an extension such as **Live Server** in Visual Studio Code.
